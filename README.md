# 🌍 Travel Guide App

An AI-powered Android travel guide app built with Kotlin that helps users discover destinations, plan trips, and explore the world.

## Features
- 🤖 AI-powered destination recommendations (updates automatically)
- 🔍 Worldwide destination search (any city in the world)
- 📸 Real photos from Unsplash
- 🗺️ Interactive Google Maps with color-coded markers
- 📍 Detailed destination info (weather, currency, language, population)
- 🌤️ Live weather data for every destination
- ⭐ Wishlist — save your favorite destinations
- 📅 Trip Planner with date picker and budget tracking
- 📔 Travel Journal with ratings
- 🤖 AI Travel Assistant powered by Llama 3 (Groq)
- 🎨 Polished dark UI throughout

## Tech Stack
- Kotlin
- MVVM Architecture
- Room Database (local storage)
- Navigation Component
- Retrofit (API calls)
- Glide (image loading)
- Coroutines & LiveData
- Google Maps SDK
- Nominatim (OpenStreetMap) — free worldwide search
- Unsplash API — real travel photos
- RestCountries API — currency & language data
- Open-Meteo API — live weather data
- Groq API (Llama 3) — AI recommendations & assistant
